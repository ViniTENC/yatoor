# gstack

This repo uses the [gstack](https://github.com/garrytan/gstack) skill suite. If you're a fresh clone without it, install once:

```
git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/.claude/skills/gstack
cd ~/.claude/skills/gstack && ./setup --team
```

(Requires `bun` — the setup script prints install instructions if missing.)

For all web browsing, use the gstack `/browse` skill — never `mcp__claude-in-chrome__*` tools.
